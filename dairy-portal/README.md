# FreshDairy - Landing Page

Landing page modern untuk portal perusahaan susu FreshDairy.

## 📁 File Structure

```
dairy-portal/
├── index.html      (311 baris) - Struktur halaman HTML5
├── styles.css      (648 baris) - Styling modern & responsive
├── script.js       (281 baris) - Interaktivitas & animasi
└── README.md       - Dokumentasi
```

### 1. Design Modern
- ✅ Color scheme segar (biru, putih, hijau)

- ✅ Shadow effects & gradients
- ✅ Smooth animations & transitions

- ✅ Headline catchy: "Susu Segar dari Alam untuk Keluarga Anda"

## 🚀 Cara Menjalankan

1. Buka file `index.html` di browser
2. Atau gunakan live server:
   ```bash
   # Dengan Python
   python -m http.server 8000
   
   # Dengan Node.js
   npx serve
   ```
