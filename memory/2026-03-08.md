# 2026-03-08 - Sunday

## Database Permission Fix

**Time:** 16:22 (Asia/Jakarta)

**Issue:** 6 tables in apistreamhub-db were owned by `postgres` instead of `apistreamhub`:
- campaigns
- layouts
- screen_group_items
- screen_groups
- screens
- templates

**Fix Applied:**
```bash
docker exec apistreamhub-db psql -U postgres -d apistreamhub -c "
ALTER TABLE campaigns OWNER TO apistreamhub;
ALTER TABLE layouts OWNER TO apistreamhub;
ALTER TABLE screen_group_items OWNER TO apistreamhub;
ALTER TABLE screen_groups OWNER TO apistreamhub;
ALTER TABLE screens OWNER TO apistreamhub;
ALTER TABLE templates OWNER TO apistreamhub;
"
```

**Result:** ✅ All permissions now correct - all 13 tables and 5 sequences owned by apistreamhub

**Note:** The fix-db-permissions.sh script didn't work properly, had to run ALTER TABLE commands manually.
