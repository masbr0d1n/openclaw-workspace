## 🏗️ Page Sections

### 1. Navigation Bar
- Sticky positioning
- Logo + 3 nav links + CTA button
- Mobile: Hide nav links, show CTA only

### 2. Hero Section
- Gradient background (Primary → Secondary)
- Value proposition headline
- Subheading with benefit statement
- Dual CTA buttons (Primary + Outline)

### 3. Features Section
- 6 feature cards in responsive grid
- Icon + Title + Description per card
- Hover effects (lift + shadow)
- Features:
  - Video Management
  - Keamanan Enterprise
  - Analytics Dashboard
  - Monetisasi Fleksibel
  - Global CDN
  - Multi-Platform

### 4. Pricing Section
- 3-tier pricing cards
- Middle card highlighted as "Most Popular"
- Feature lists with checkmarks
- CTA buttons per tier
- Pricing:
  - Starter: Rp 999rb/bulan
  - Professional: Rp 2.499jt/bulan
  - Enterprise: Custom

### 5. Call-to-Action Section
- Dark gradient background
- Compelling headline
- Social proof (500+ companies)
- Primary CTA button
- Trust indicator (no credit card required)

### 6. Footer
- 4-column grid layout
- Company info + social links
- Product links
- Company links
- Contact information
- Copyright + legal links
