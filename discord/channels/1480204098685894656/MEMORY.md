## Core Design Principles

1. **Clarity** — The best interface requires no explanation
2. **Consistency** — Same pattern, same behavior — always
3. **Accessibility** — Designed for the edges, works for the center
4. **Efficiency** — Respect the user's time and cognitive load
5. **Delight** — Good UX is functional; great UX is memorable

---

## Required Design States
