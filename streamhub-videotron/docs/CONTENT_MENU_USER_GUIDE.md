## Overview

Menu Content adalah pusat manajemen konten di Videotron. Semua sub-menu saling terhubung dalam workflow yang terstruktur.

---

## Sub-Menus

### 1. Media Library
**Fungsi:** Upload dan kelola media (video, gambar)

**Fitur:**
- Upload multiple files
- Drag & drop support
- Metadata editing (title, description, tags)
- Thumbnail generation
- Preview playback
- Bulk delete

**Aksi:**
- Upload → Select files → Add metadata → Save
- Edit → Click media → Update details → Save
- Delete → Select → Delete

---

### 2. Playlists
**Fungsi:** Susun urutan media untuk playback

**Fitur:**
- Create playlist
- Drag & drop items
- Set duration per item
- Reorder sequence
- Preview playlist

**Aksi:**
- Create → Name → Add media → Arrange → Save
- Edit → Drag items → Save
- Delete → Select → Delete

---

### 3. Layouts
**Fungsi:** Design tampilan visual untuk display

**Fitur:**
- Zone-based design
- Resolution presets (FHD, HD, 4K, Vertical)
- Widget library (video, image, text, clock, weather)
- Preview mode
- Duplicate layout

**Aksi:**
- Create → Select resolution → Add zones → Assign content → Save
- Edit → Modify zones → Save
- Delete → Select → Delete

---

### 4. Feeds (Dynamic Content)
**Fungsi:** Konten dinamis dari sumber data eksternal

**Fitur:**
- RSS feed integration
- API data source
- Auto-refresh
- Template mapping

**Aksi:**
- Create feed → Configure source → Map fields → Save

---

### 5. Campaign
**Fungsi:** Manajemen kampanye untuk deployment

**Fitur:**
- Schedule (start/end date)
- Target screen selection
- Priority setting
- Layout assignment
- Status tracking (draft, pending, active, completed)

**Aksi:**
- Create → Configure → Submit for approval
- Edit → Modify → Re-submit
- Activate → Manual activation
- Deactivate → Stop campaign

---

### 6. Approval Workflow
**Fungsi:** Review dan approval konten

**Fitur:**
- Pending requests list
- Approval history
- Feedback system
- Multi-level approval

**Aksi:**
- Review → Open request → Preview content
- Approve → Click Approve → Confirm
- Reject → Click Reject → Add feedback → Confirm

---

### 7. Archive
**Fungsi:** Arsip konten yang sudah tidak aktif

**Fitur:**
- Auto-archive completed campaigns
- Search & filter
- Restore functionality
- Permanent delete
- Retention policy

**Aksi:**
- View → Browse archived items
- Restore → Select → Restore
- Delete → Select → Permanent delete

---

## Workflow Best Practices

### ✅ DO
- Always preview before submitting
- Use descriptive names for playlists/layouts
- Tag media for easy searching
- Submit for approval early
- Check campaign schedule conflicts

### ❌ DON'T
- Skip approval workflow
- Leave campaigns without end date
- Ignore feedback from approvers
- Delete media used in active campaigns

## Common Tasks

### Task: Upload New Video
1. Go to Media Library
2. Click Upload
3. Select video file
4. Fill: title, description, tags
5. Select channel
6. Click Save
7. Wait for thumbnail generation

### Task: Create Simple Campaign
1. Upload media to Media Library
2. Create Playlist → Add media
3. Create Layout → Add video zone → Assign playlist
4. Create Campaign → Select layout → Set schedule → Submit
5. Wait for approval
6. Campaign goes live

### Task: Update Active Campaign
1. Go to Campaign → Active
2. Select campaign → Edit
3. Modify content
4. Submit for approval
5. Fast-track if urgent

## Troubleshooting

| Issue | Solution |
|-------|----------|
| Upload failed | Check file size (max 100MB), format (MP4, JPG, PNG) |
| Preview not loading | Refresh page, clear cache |
| Approval stuck | Contact approver, check workflow settings |
| Campaign not displaying | Check schedule, screen status, priority |
